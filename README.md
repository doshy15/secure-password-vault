# Secure Password Vault

Secure Password Vault is an offline-first Windows password and private record manager by PracticalForge Software.

It helps users store passwords, secure notes, private lists, personal records, bank details, and 2FA backup codes in a local vault on their own Windows computer.

## Privacy model

Secure Password Vault is offline-first.

Your vault data stays on your Windows computer. PracticalForge Software does not collect, read, upload, sell, or share your saved passwords, master password, vault contents, vault backups, or private records.

Paid editions use internet access only for license activation and verification.

## Master password note

PracticalForge Software cannot recover, reset, bypass, or decrypt a lost master password.

Users are responsible for keeping their master password safe and maintaining their own secure backups.

## Windows SmartScreen notice

Because this is independent Windows software, Windows may show an "Unknown Publisher" or SmartScreen warning during installation.

This does not automatically mean the file is unsafe. Users may scan the installer with antivirus software or VirusTotal before running it.

## Mobile note

Secure Password Vault Pro includes QR / mobile pairing and transfer-related tools prepared for future mobile workflows.

The separate mobile app is currently under development and is not included as a separate released product yet. Future mobile features, companion apps, or mobile releases are not guaranteed unless clearly stated.
