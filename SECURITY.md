# Security Policy

This page explains how to report security-related issues for Secure Password Vault by PracticalForge Software.

## Reporting a security issue

If you believe you found a security issue, please contact:

support@practicalforge.com

Please include:

- Product edition: Demo, Standard, or Pro
- Windows version
- App version, if known
- Clear steps to reproduce the issue
- Screenshots, if useful

## Do not send private vault data

Do not send:

- Master password
- Vault password
- Saved passwords
- 2FA backup codes
- Vault database files
- Backup files
- Exported browser CSV files
- Private vault contents

PracticalForge Software does not need private vault data to review a security report.

## Master password recovery

Secure Password Vault is designed as an offline-first local vault.

PracticalForge Software does not store user master passwords and cannot recover, reset, bypass, or decrypt a lost master password.

## Responsible reporting

Please do not publicly disclose a security issue before PracticalForge Software has had a reasonable opportunity to review it.

## Supported product

Security reports currently apply to:

- Secure Password Vault for Windows
