# Support

Support for Secure Password Vault is available through the official PracticalForge Software support page and support email.

## Support page

https://practicalforge.com/support.html

## Support email

support@practicalforge.com

## What to include

When contacting support, include:

- Product edition: Demo, Standard, or Pro
- Windows version
- Purchase email, if the question is license-related
- A clear description of the issue
- A screenshot, if useful

## Do not send private data

Do not send:

- Master password
- Vault password
- Saved passwords
- 2FA backup codes
- Vault files
- Backup files
- Exported browser CSV files
- Private vault contents

PracticalForge Software support will never ask for your master password or private vault data.

## Master password recovery

Secure Password Vault is offline-first.

PracticalForge Software does not store your master password and cannot recover, reset, bypass, or decrypt a lost master password.

Users are responsible for keeping their master password safe and maintaining their own secure backups.

## Windows SmartScreen

Because Secure Password Vault is independent Windows software, Windows may show an "Unknown Publisher" or SmartScreen warning during installation.

This does not automatically mean the installer is unsafe. Users may scan the installer with antivirus software or VirusTotal before running it.
